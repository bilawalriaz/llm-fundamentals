The Flan Collection

Chung, Hou, Longpre, Zoph, Tay, Fedus, Li, Wang, Dehghani, Brahma, Webson, Clark, Le, Zhao, Le, & Wei (Google)
arXiv:2301.13688
January 2023
arXiv Paper

The Flan Collection scales instruction fine-tuning to 1,800+ tasks and demonstrates that the right mix of task formats — zero-shot, few-shot, and chain-of-thought prompts — dramatically improves generalization. Flan-T5 and Flan-PaLM set new standards for instruction-following by showing that mixed prompt training, input inversion (reversing input-output mappings), and careful task balancing produce models that generalize to entirely unseen tasks. Flan-T5-XXL outperforms PaLM-540B on some benchmarks despite being 13× smaller, establishing instruction tuning as the single most impactful post-training technique.

1. Motivation: Beyond Single-Task Fine-Tuning

Before the Flan Collection, instruction fine-tuning was typically done on a single task or a small number of tasks. Models like T5 were fine-tuned individually for each downstream task, requiring separate model weights for each application. The Flan Collection asks: what happens if you fine-tune on hundreds or thousands of diverse tasks simultaneously?

The hypothesis is that training on a massive diversity of tasks teaches the model a general capability — instruction following — that transfers to new, unseen tasks. This is analogous to how a student who has practiced many different types of problems develops general problem-solving skills that apply to novel situations. The paper provides definitive evidence for this hypothesis.

"The right instruction fine-tuning mix can make a model strictly better than its pretrained version — a Pareto improvement across all benchmarks."

2.2 Task Format Diversity

A critical innovation is generating multiple prompt formats per task. For a sentiment classification task, the training data might include:

  • Zero-shot: "Is the following review positive or negative? Review: [text]"
  • Few-shot: "Here are some examples of positive and negative reviews... Now classify: [text]"
  • Chain-of-thought: "Let's think step by step. The review mentions [analysis]. Therefore, the sentiment is [answer]."
  • Input-inverted: "Given the label 'positive', generate a review that would have this sentiment."

3. Mixed Prompt Training

3.1 The Three Prompt Formats

For each task, the Flan Collection generates training instances in three formats with specific percentages:

"Training on a mix of zero-shot, few-shot, and chain-of-thought prompts produces models that perform well across ALL evaluation settings — even settings never seen during training. Each format contributes unique learning signal that the others cannot provide."

The mixed format approach works because each format teaches a different aspect of instruction following: zero-shot teaches direct task execution, few-shot teaches in-context learning from examples, and CoT teaches reasoning and explanation. The combination produces a model that can handle any prompt format it encounters at test time.

4. Input Inversion

4.1 The Technique

Input inversion is a data augmentation technique that reverses the input-output mapping of a task. For a summarization task (document → summary), the inverted version asks the model to generate a document given a summary. For sentiment classification (review → label), the inverted version asks the model to generate a review given the sentiment label.

Formally, for a task with input x and output y: 

Standard:      x → y    ("Classify this review: [text] → Positive")
Input-inverted: y → x    ("Write a positive review: [label] → [generated text]")

4.2 Why Input Inversion Works

Input inversion serves several purposes:

  • Flexible I/O mapping: It teaches the model that the relationship between inputs and outputs is bidirectional — the model learns to flexibly map between different input/output spaces.
  • Data augmentation: It doubles the effective training data without requiring new annotations. Each task produces two training formats.
  • Robustness: It prevents the model from relying on superficial cues (e.g., "if the input looks like a review, output a label") and forces it to understand the actual task semantics.

Input inversion provides a consistent ~3-4% improvement on held-out tasks. The gain is larger on held-out tasks than on seen tasks, confirming that input inversion improves generalization rather than memorization.

💡
Practical application: Input inversion is a simple, underappreciated data augmentation strategy. For any task with a clear input-output mapping, generating inverted examples is cheap (can be done automatically) and provides measurable gains. This technique has been adopted in various forms by subsequent instruction-tuning efforts.

5. Task Balancing

5.1 The Frequency Bias Problem

When training on 1,800+ tasks, some tasks have thousands of examples while others have only a few. Without balancing, the model would be dominated by high-frequency tasks (like sentiment analysis) and neglect low-frequency tasks (like rare NLU tasks). This creates a frequency bias that hurts generalization.

5.2 Balancing Strategy

The Flan Collection uses example-level balancing: each task is sampled proportional to a smoothed frequency: 

P(task) ∝ N_task^α

where:
  N_task = number of examples in the task
  α = 0.7 (smoothing parameter)
  α = 0: uniform across tasks (ignore frequency)
  α = 1: proportional to frequency (no smoothing)
  α = 0.7: compromise — high-frequency tasks are upsampled but not dominant

Key findings: CoT data is the most impactful source for reasoning benchmarks, confirming that step-by-step reasoning examples teach general reasoning capability. MMLU tasks matter most for MMLU (obviously), but removing them has a modest effect on held-out generalization — suggesting the reasoning skills transfer more than the knowledge.

6. Flan-T5: The Starting Checkpoint

6.1 Why Flan-T5?

A crucial design decision is using Flan-T5 (instruction-finetuned T5) as the starting checkpoint rather than vanilla T5. The paper demonstrates that Flan-T5 provides a strictly better starting point — a Pareto improvement — across all evaluation settings.

Starting CheckpointHeld-out TasksMMLUTraining Speed
Vanilla T5-XXL42.348.7Baseline
Flan-T5-XXL53.755.83× faster convergence

Flan-T5 converges 3× faster and achieves higher final performance. The instruction-finetuned checkpoint already "understands" instruction following — it just needs to be exposed to more diverse tasks to expand its repertoire. This is a strong argument for iterative instruction tuning: build on previous instruction-tuned models rather than starting from scratch.

6.2 Flan-PaLM: Scaling the Backbone

Applying the same Flan methodology to PaLM (540B parameters) yields Flan-PaLM, which achieves even stronger results. The combination of scale + instruction tuning + CoT data is particularly powerful:

Notably, Flan-T5-XXL (11B) outperforms vanilla PaLM-540B on some benchmarks despite being 50× smaller. This demonstrates that instruction tuning can compensate for a massive scale disadvantage on certain tasks.

7. Held-In vs. Held-Out Scaling

7.1 The Generalization Curve

The paper measures performance on both held-in tasks (included in training) and held-out tasks (excluded from training, used only for evaluation). The scaling behavior is revealing:

  • Held-in performance improves steadily with more training tasks, following a log-linear curve
  • Held-out performance also improves, but with a lag — it takes more tasks before held-out gains become significant
  • The gap narrows as more tasks are added — with 1,800 tasks, held-out performance approaches held-in performance

This confirms that the model is learning a general instruction-following capability, not just memorizing specific tasks. The more diverse the training mixture, the better the model generalizes to new task formats.

7.2 Template Diversity

The paper also varies the number of prompt templates per task. More templates per task means the model sees the same task in more different formats, which improves generalization:

More templates reduce the held-in/held-out gap, confirming that format diversity teaches transferable skills rather than format-specific memorization.

8. Comparison with Other Approaches

vs. P3++ (Promptsource)

P3++ (Public Pool of Prompts) is a related effort to aggregate diverse prompt templates. Key differences:

  • P3++ focuses on prompt template diversity; Flan focuses on task diversity + format mixing
  • Flan includes chain-of-thought data; P3++ does not
  • Flan uses input inversion; P3++ does not
  • Flan's task balancing (α=0.7) is more sophisticated than P3++'s uniform sampling

On shared benchmarks, Flan-T5 outperforms P3++ models by 3-5%, primarily due to CoT data and input inversion.

vs. Super-Natural Instructions

Super-Natural Instructions (SNI) aggregates 1,600+ NLP tasks with natural language instructions. Key differences:

  • SNI uses only zero-shot format; Flan mixes zero/few/CoT
  • Flan's CoT data provides significant advantage on reasoning tasks
  • SNI includes more diverse languages; Flan focuses on English
  • Flan's input inversion provides additional data augmentation

On the SNI benchmark, Flan-T5 achieves competitive or better performance despite SNI being specifically designed for that evaluation.

vs. OPT-IML-Max

OPT-IML-Max (Meta) also aggregates diverse instruction-following data. Key differences:

  • OPT-IML uses a single OPT backbone; Flan uses both T5 (encoder-decoder) and PaLM (decoder-only)
  • Flan's mixed prompt training provides more format diversity
  • OPT-IML includes more safety-related tasks; Flan focuses more on reasoning
  • Flan-T5's encoder-decoder architecture is particularly effective for tasks with clear input-output structure

On MMLU, Flan-T5-XXL outperforms OPT-IML-Max (30B) despite being 3× smaller, demonstrating the efficiency of the Flan training recipe.

9. Limitations

  • English-only: The Flan Collection is primarily English. Multilingual instruction tuning was not explored.
  • Task selection bias: The 1,800 tasks skew toward NLP benchmarks. Real-world tasks (creative writing, long-form generation, multi-turn dialogue) are underrepresented.
  • Template quality: Many templates are auto-generated or crowd-sourced, with variable quality. Some templates may be misleading or confusing.
  • Compute cost: Training on 1,800+ tasks with multiple templates per task is computationally expensive, even for T5-XXL.
  • No RLHF: The Flan approach uses only SFT, without preference-based alignment (RLHF/DPO). Modern post-training typically combines SFT with preference optimization.
  • Overfitting to benchmarks: The heavy use of benchmark-derived tasks may inflate held-in performance without proportional gains on truly novel tasks.

10. Practical Implications

The Flan Collection established the template for modern instruction tuning:

  • Diverse tasks matter: Training on thousands of diverse tasks produces general instruction-following capability. This principle underpins every subsequent instruction-tuning effort.
  • Mixed format training is essential: Combining zero-shot, few-shot, and CoT formats produces models that handle any prompt style. This connects to Paper 09: Self-Instruct, which generates diverse instruction formats.
  • Input inversion is a practical augmentation: Simple to implement, provides measurable gains, and is applicable to any task with clear I/O mappings.
  • Task balancing prevents frequency bias: The α=0.7 smoothing strategy is a practical recipe for handling imbalanced task distributions.
  • Build on instruction-tuned checkpoints: Flan-T5 as a starting point for further tuning is strictly better than vanilla T5. This iterative approach is now standard.
🎯
Key takeaway: The Flan Collection proved that instruction fine-tuning is the single most impactful post-training technique. By training on 1,800+ tasks with mixed prompt formats, input inversion, and careful task balancing, Flan-T5 achieves Pareto improvements over vanilla T5 and matches much larger models. The mixed prompt training methodology — combining zero/few/CoT formats — is now the standard approach for instruction tuning, used by LIMA, Zephyr, ORPO, and essentially all modern instruction-tuned models.
